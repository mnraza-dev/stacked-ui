# Security Policy

## Supported Versions

We provide security updates and patches for the following versions of Stacked UI:

| Package | Version | Supported |
| :--- | :--- | :--- |
| `stackedui` | `0.1.x` | :white_check_mark: |
| `stackedui-cli` | `1.0.x` | :white_check_mark: |
| Legacy / pre-release | `< 0.1.0` | :x: |

---

## Reporting a Vulnerability

The Stacked UI maintainers take the security of our library and its downstream consumers seriously. If you discover a security vulnerability in Stacked UI, please report it responsibly rather than opening a public issue.

### How to Report

Please send an email detailing the vulnerability to **`mnraza.dev@gmail.com`** with the subject line:
`[SECURITY] Vulnerability Report in Stacked UI`

Include the following information in your report:

1. **Description:** A detailed explanation of the vulnerability and its potential impact.
2. **Steps to Reproduce:** Minimal reproducible code snippet or repository demonstrating the issue.
3. **Affected Versions:** Which packages and versions are impacted.
4. **Proposed Fix (Optional):** If you have a remediation patch or suggestion, please include it.

---

## Response Timeline

- **Initial Response:** Within **48 hours**, we will acknowledge receipt of your report and begin investigating.
- **Triage & Status Update:** Within **5 business days**, we will confirm the issue and provide an estimated timeline for remediation.
- **Patch Release:** Security patches will be prioritized and published as a patch release (`x.y.Z`) to npm as swiftly as possible.
- **Public Disclosure:** Public disclosure will occur after a patch has been published and consumers have had reasonable opportunity to update.

Thank you for helping keep Stacked UI and the open-source community secure!
