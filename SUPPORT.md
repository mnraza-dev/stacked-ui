# Getting Help & Support

Thank you for building with **Stacked UI**! This document provides information on how to get assistance, report bugs, ask architectural questions, and connect with the maintainers.

---

## Community Support

- **Bug Reports & Issues:** If you have encountered a bug or unexpected behavior in Stacked UI, please check existing issues and open a new report using our [Bug Report Template](https://github.com/mnraza-dev/stacked-ui/issues).
- **Feature Requests & Ideas:** Have an idea for a new component or styling utility? Share your proposal in [GitHub Discussions](https://github.com/mnraza-dev/stacked-ui/discussions).
- **Q&A & Implementation Help:** For usage questions, theme customization help, or integration queries, please participate in GitHub Discussions under the "Q&A" category.

---

## Before Asking for Help

To help us resolve your question as quickly as possible:

1. **Check the Documentation:** Comprehensive guides and interactive examples are available on our [Documentation Website](https://stacked-ui.vercel.app).
2. **Search Existing Issues:** Check both open and closed issues on GitHub to see if your question or issue has already been addressed.
3. **Provide a Minimal Reproduction:** When reporting an issue, provide a minimal, reproducible code example (via CodeSandbox, StackBlitz, or a GitHub repository).
